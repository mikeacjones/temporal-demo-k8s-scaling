Workers that scale themselves.

A traffic director workflow sends waves of orders. KEDA watches each worker version's task queue backlog and slot utilization, and the Worker Controller runs every version side by side, ramping new ones in while old ones drain.

Traffic director

An entity workflow on its own worker. It loops forever through idle → ramp → peak → ramp → cooldown, continuing-as-new every cycle.

02

Temporal task queue

Each order is a pinned workflow. Workers only get 4 activity slots, so traffic beyond that waits in the queue as backlog.

03

KEDA, per version

The Worker Controller renders one ScaledObject per Build ID that scales on that version's backlog and slot utilization.

04

Worker Controller

Every few cycles a new version rolls out progressively (25% → 50% → 100%) while in-flight orders drain on the old one.
